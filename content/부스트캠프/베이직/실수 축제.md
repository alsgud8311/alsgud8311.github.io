## [실수 코드] 

```js
  // rest => 지역번호를 뺀 나머지 뒷번호
  const rest = tel.substring(3);

  if (top === "001" || top === "002") {
    if (rest.length > 12 || rest.length < 8) return failure;
    return ["국제전화", "O"];
  }
```

## [실수 코드 테스트케이스]
```js
console.log(solution("002--22344--12344121123"));
```

- 의도했던 출력 : [ "국제전화", "X" ]

- 실제 출력: [ "전국", "X" ]

## [문제 상황 분석]
국제전화일 경우 001 또는 002 이후 뒷 번호가 8~12자까지 허용하여 조건을 만족할 경우에는 [ "국제전화", "O" ]를 출력시키고, 그렇지 않을 경우 [ "국제전화", "X" ]를 출력시키려 했으나, 실수로 failure 변수에 할당된 배열 자체에는 [ "전국", "X" ]밖에 담겨있지 않아 예상했던 출력과는 달랐던 실수였다.

## [문제 해결]
국제 전화와 국내 전화를 구분하기 위해 failure를 Object로 만들어 각 상황에 맞는 전화번호 오류를 출력하도록 만들었다

```js
const failure = { domestic: ["전국", "X"], global: ["국제전화", "X"] };
...
  if (top === "001" || top === "002") {
    if (rest.length > 12 || rest.length < 8) return failure.global;
    return ["국제전화", "O"];
  }
  }
```

## [문제 해결 후 테스트]

```js
// output: [ '국제전화', 'O' ]
console.log(solution("002-2234-1234"));
// output: [ '국제전화', 'X' ]
console.log(solution("002-22344-12344121123"));
```
