자신이 기억한 멜로디를 가지고 방금그곡을 이용해 음악 찾기

반복 재생 -> 끝과 처음이 이어서 재생된 멜로디일 수도 있음
+ 중간에 음악을 끊을 경우 곡이 다를 수도 있음
=> 기억한 멜로디를 재생 시간과 제공된 악보를 보면서 비교

음악제목, 재생되고 끝난시간, 악보
음 -> C, C#, D, D#, E, F, F#, G, G#, A, A#, B 12개

1. 악보의 총 음 개수를 구한다
2. 시 -> 분으로 바꾼 뒤, 얼마만큼 재생이 되었는지 분단위로 파악한다
3. 분단위로 파악한 뒤에는 기존 음악의 멜로디에 반복된 수만큼 악보 또한 반복해준 악보를 배열에 저장한다
4. 배열을 돌면서 해당 문자열이 포함되어 있는지 검색한다
